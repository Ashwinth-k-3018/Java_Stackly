### Features
- Register Patient
- Add Doctor
- Book Appointment
- Cancel Appointment
- View Available Slots
- View Doctor Schedule
- View Patient History
- Search Doctor by Specialization

### Modules
- Main
- Patient
- Doctor
- Appointment
- HospitalService

- ## MySQL Projects

This folder contains SQL assignments and mini-projects developed to practice database management, SQL queries, joins, aggregate functions, and real-world database scenarios using MySQL.

### 1. Banking Scenario Assignment
**File:** `Banking_Scenario_Assignment.sql`

- Practice banking-related database operations.
- Apply SQL queries to banking scenarios.

### 2. Customer Order Assignment
**File:** `Customer_Order_Assignment.sql`

- Manage customer and order-related data.
- Practice retrieving order details using SQL queries.
- Explore relationships between customers and orders.

### 3. Employee Management Assignment
**File:** `Employee_Management_Assignment.sql`

- Manage employee information.
- Practice filtering, sorting, and updating records.
- Use aggregate functions to analyze employee data.

### 4. Hotel Management Mini Project
**File:** `Hotel_Management_Mini_prj.sql`

- Practice hotel-related database operations.
- Retrieve and manage records using SQL queries.
- Work with hotel management data.

### 5. Railway Reservation Assignment
**File:** `Railway_Reservation_Assignment.sql`

- Practice railway reservation-related database operations.
- Work with passenger and reservation data.
- Retrieve records using SQL queries.

### 6. Students Table Assignment
**File:** `Students_Table_Assignment.sql`

- Manage student records and marks.
- Practice `SELECT`, `INSERT`, `UPDATE`, and `DELETE`.
- Use aggregate functions, `GROUP BY`, `HAVING`, and `ORDER BY`.

### 7. Vehicle Service Center Mini Project
**File:** `Vehicle_Service_Center_Mini_prj.sql`

- Manage vehicle service center data.
- Work with customers, vehicles, service records, and bills.
- Retrieve related information using SQL joins.
- Calculate billing totals using aggregate functions.
- Practice date functions to retrieve service records.

### MySQL Concepts Practiced
- Database and Table Creation
- DDL, DML, and DQL Commands
- Constraints and Data Types
- Filtering and Sorting
- SQL Joins
- Aggregate Functions
- `GROUP BY` and `HAVING`
- Subqueries and Operators
- Date Functions
- Real-World Database Scenarios
