# Java Stackly

This repository contains the Core Java projects 

## Hospital Appointment System

This project is used to manage patients, doctors and appointments.

### Features
- Register Patient
- Add Doctor
- Book Appointment
- Cancel Appointment
- View Available Slots
- View Doctor Schedule
- View Patient History
- Search Doctor by Specialization

### Modules
- Main
- Patient
- Doctor
- Appointment
- HospitalService

## Student Management System

This project is used to manage student details, marks, attendance and courses.

### Features
- Add Student
- Display Students
- Search Student by ID
- Search Student by Name
- Update Marks
- Update Attendance
- Calculate Grade
- Remove Student
- Find Topper
- Save and Load Student Data

### Modules
- Main
- Student
- Course
- StudentStatus
- StudentService
- StudentFileService
